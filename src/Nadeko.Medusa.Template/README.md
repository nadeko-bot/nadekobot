# nadeko-medusa

Project template for a [NadekoBot](https://github.com/nadeko-bot/nadekobot) medusa (plugin).

```sh
dotnet new install nadeko-medusa --nuget-source https://www.myget.org/F/nadeko/api/v3/index.json
dotnet new nadeko-medusa
```

The guide: https://docs.nadeko.bot/medusa/creating-a-medusa/
